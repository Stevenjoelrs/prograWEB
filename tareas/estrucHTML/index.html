¿Qué es Python?

Python es un lenguaje de programación popular. Fue creado por Guido van Rossum y lanzado en 1991.

Se utiliza para:

  • Desarrollo web (lado del servidor)
  • Desarrollo de software
  • Matemáticas
  • Scripting de sistemas

¿Qué puede hacer Python?

  • Usarse en un servidor para crear aplicaciones web.
  • Usarse junto con otro software para crear flujos de trabajo.
  • Conectarse a sistemas de bases de datos; también leer y modificar archivos.
  • Manejar grandes volúmenes de datos y realizar matemáticas complejas.
  • Servir para prototipado rápido o para desarrollo de software listo para producción.

¿Por qué Python?

  • Funciona en distintas plataformas (Windows, Mac, Linux, Raspberry Pi, etc.).
  • Tiene una sintaxis simple, similar al idioma inglés.
  • Permite escribir programas con menos líneas que otros lenguajes de programación.
  • Se ejecuta mediante un sistema intérprete: el código se ejecuta tan pronto se escribe, lo que hace que el prototipado sea muy rápido.
  • Puede tratarse de forma procedural, orientada a objetos o funcional.

Dato a tener en cuenta: la versión principal más reciente de Python es Python 3, que es la que se usa en este tutorial. Python usa las nuevas líneas para terminar una orden (otras lenguajes suelen usar punto y coma o paréntesis) y se apoya en la indentación, con espacios en blanco, para definir el alcance, como el alcance de los bucles, las funciones y las clases.

print("Hello, World!")

¿Cómo hacer funcionar un programa?

Python es un lenguaje de programación interpretado. Esto significa que, como desarrollador, escribes archivos de Python (con extensión .py) en un editor de texto y luego pasas esos archivos al intérprete de Python para que se ejecuten.

1. Comprobar que Python está instalado

Muchas PC con Windows y Mac ya traen Python preinstalado. Para comprobarlo, escribe en la línea de comandos:

python --version

Si Python no está instalado, puedes descargarlo gratis desde la página oficial: https://www.python.org/

2. Ejecutar un archivo de script

Crea tu primer archivo de Python, llamado hello.py, en cualquier editor de texto:

# hello.py
print("Hello, World!")

Guarda el archivo, abre la línea de comandos, navega hasta la carpeta donde lo guardaste y ejecuta: 

python hello.py

La salida será:

Hello, World!

Así has escrito y ejecutado tu primer programa en Python.

3. Usar la línea de comandos de Python (REPL)

Para probar una cantidad pequeña de código a veces es más rápido no escribirlo en un archivo: Python puede ejecutarse como una línea de comandos por sí mismo. Escribe python (o py) y verás el símbolo >>>:

>>> print("Hello, World!")
Hello, World!

Cuando termines, sal de la interfaz con:

exit()

Tipos de Datos Principales

Python cuenta con diferentes tipos de datos incorporados listos para usar:

  • Enteros y Flotantes (int, float): edad = 25, precio = 19.99
  • Cadenas de texto (str): nombre = "Steven"
  • Booleanos (bool): es_mayor = True, tiene_descuento = False
  • Listas (list): Colecciones ordenadas y modificables. frutas = ["manzana", "pera", "uva"]
  • Tuplas (tuple): Colecciones ordenadas pero inmutables (no se pueden cambiar). coordenadas = (10.5, 20.3)
  • Diccionarios (dict): Colecciones de pares clave-valor. usuario = {"nombre": "Steven", "rol": "admin"}

Variables Dinámicas

Las variables son contenedores para almacenar valores de datos.

Python tiene un sistema de tipado dinámico: no existe un comando para declarar una variable; una variable se crea en el momento en que se le asigna un valor por primera vez, no necesita ser declarada con un tipo en particular e incluso puede cambiar de tipo después de haber sido asignada.


x = 5             # x es de tipo int
x = "Sally"       # x ahora es de tipo str
print(x)

Si quieres especificar el tipo de dato de una variable, esto se puede hacer con el casting: 


x = str(3)    # x será '3'
y = int(3)    # y será 3
z = float(3)  # z será 3.0

Puedes obtener el tipo de dato de una variable con la función type():


x = 5
y = "John"
print(type(x))   # <class 'int'>
print(type(y))   # <class 'str'>

Nota: los nombres de variables distinguen entre mayúsculas y minúsculas: a y A son dos variables diferentes.

Expresiones Aritméticas

Los operadores aritméticos se utilizan con valores numéricos para realizar operaciones matemáticas comunes.

Operador Nombre Ejemplo
+ Suma x + y
- Resta x - y
* Multiplicación x * y
/ División x / y
% Módulo (resto) x % y
** Potencia x ** y
// División entera x // y

Ejemplo usando los distintos operadores aritméticos:


x = 15
y = 4

print(x + y)    # 19
print(x - y)    # 11
print(x * y)    # 60
print(x / y)    # 3.75
print(x % y)    # 3
print(x ** y)   # 50625
print(x // y)   # 3

División en Python

Python tiene dos operadores de división:

  • / — División (siempre devuelve un float)
  • // — División entera (siempre devuelve un entero)

x = 12
y = 5

print(x / y)    # 2.4   (la división siempre devuelve un float)
print(x // y)   # 2     (la división entera redondea hacia abajo)

Estructuras de Control (Condicionales)

Nota importante: Python usa la indentación (espacios a la izquierda) para definir bloques de código en lugar de usar llaves {}.


edad = 18

if edad >= 18:
    print("Eres mayor de edad.")
elif edad == 17:
    print("Te falta un año.")
else:
    print("Eres menor de edad.")

Bucles (Ciclos)

Los bucles permiten repetir bloques de código.

1. Bucle For

Se utiliza para iterar sobre una secuencia (como una lista, un texto o un rango de números).


nombres = ["Steven", "Ana", "Carlos"]
for nombre in nombres:
    print("Hola " + nombre)

# Iterar un número específico de veces
for i in range(3):
    print("Iteración número", i)

2. Bucle While

Se repite mientras una condición siga siendo verdadera (True).


contador = 0
while contador < 3:
    print(contador)
    contador += 1  # Incrementamos en 1 para que no sea un bucle infinito

Funciones

Las funciones agrupan código para que pueda ser reutilizado. Se definen con la palabra reservada def. 


def sumar(a, b):
    resultado = a + b
    return resultado

suma_total = sumar(5, 10)
print("La suma es:", suma_total) # Imprime 15

Manejo de Errores (Excepciones)

Se utiliza para evitar que el programa se caiga abruptamente cuando ocurre un fallo.


try:
    resultado = 10 / 0
except ZeroDivisionError:
    print("Error: No se puede dividir por cero.")
finally:
    print("Esta línea siempre se ejecutará al final.")

¿Cómo importar librerías?

Para usar funciones avanzadas o herramientas externas, debes importarlas al inicio de tu archivo.

Importación básica


import math
print(math.sqrt(25)) # Uso: modulo.funcion()

Importar algo en específico


from datetime import datetime
print(datetime.now()) # Uso directo sin poner el módulo antes
